# NFT Minting Contract

## Project Description
NFT Minting Contract is a simple ERC721-style smart contract developed using Solidity. This project demonstrates how NFTs can be minted and tracked on the blockchain using a lightweight NFT contract.

## Features
- Mint NFTs
- Track Total Minted NFTs
- Lightweight Smart Contract
- Beginner-Friendly NFT Implementation

## Technologies Used
- Solidity
- Remix IDE
- MetaMask
- Remix VM

## Deployment Steps
- Open Remix IDE  
- Create `NFTMintingContract.sol`  
- Paste the smart contract code  
- Compile using Solidity `0.8.20`  
- Select `Remix VM` environment  
- Deploy the smart contract  
- Execute `mint()` function  

This project demonstrates the basic implementation of an NFT minting smart contract using Solidity and Remix IDE.
